Industrial robot visual pilot
============================

This directory contains an adapted visual derivative of the following work:

- KUKA robot descriptions, Copyright 2025 KUKA Hungaria Kft.
- https://github.com/kuka-ros/kuka_robot_descriptions
- Revision: `5ddbc41ce8726fd680bcc19562d78bcabfbdf96d`
- Source: `kuka_agilus_support/meshes/kr10_r900_2/visual/{base_link,link_1,link_2,link_3,link_4,link_5,link_6}.dae`
- Joint/visual reference: `kuka_agilus_support/urdf/kr10_r900_2_macro.xacro`
- License: Apache License 2.0, reproduced in `LICENSE`.

Modified by SmartTwin for a generic educational machine: rebase visual link
coordinates; remove source axis offsets to fit the existing native articulated
rig; scale link proportions to the authored native dimensions; substitute neutral
fitted service covers for visible source branding; smooth manufacturing radii
while retaining creases; generate explicit offline LOD; quantize delivery buffers.
Final normals use corner-angle weighting rather than face-area averaging; this
retains every position and ordered triangle, as recorded in `provenance.json`.
Per-source SHA-256 values and the pinned revision are embedded in `cad.json`.

The derivative does not contain the OEM controller, certified collision model,
mass/inertia specification, calibration or guaranteed operating limits. The
native SmartTwin J1–J6 hierarchy, TCP, tooling and custody logic remain
authoritative. This is not labelled as an exact KUKA product or endorsed by KUKA.

Reproduction: run `tooling/modeling/prepare-robot-pilot-cad.py` in an isolated
Blender process, with the seven source DAE files and the referenced xacro under
`--source`, and the new delivery path under `--output`. Source coordinates,
licensed original tessellation and its limitations remain traceable. Runtime
images/maps are generated by the native material system, not downloaded logos.
