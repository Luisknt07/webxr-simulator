Controles del escenario

Haz clic en la escena para mirar con el mouse y apuntar con el círculo central. W A S D o las flechas para caminar; clic para usar lo señalado. Esc libera el mouse para abrir los menús.

Acércate al montacargas y pulsa F para subir o bajar. En la cabina: C abre la cámara de horquillas, Shift+R alterna el retrovisor y Shift+G activa o desactiva el holograma.

En móvil usa los mandos táctiles. En RV: stick izquierdo para caminar, derecho para girar. Apunta y pulsa el gatillo para seleccionar; usa el agarre lateral en los mandos de cabina.
